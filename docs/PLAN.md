# بوابة الزيارات — خطة المرحلة الأولى (الأساس)

الدورة: بيانات ← إسناد ← تخطيط ← تنفيذ ← متابعة ← قياس ← قرار

## التطبيقات (apps) والنماذج (models)

| التطبيق | المسؤولية | النماذج |
|---|---|---|
| `accounts` | المستخدمون والأدوار والدخول برمز التحقق | `User` (البريد هو المعرّف، الدور، القسم، القطاع) · `LoginCode` (رمز OTP مُجزّأ، صلاحية، محاولات) |
| `org` | البيانات الأساسية | `Department` (القسم ومديره) · `Sector` · `School` (بطاقة المدرسة: الرقم الوزاري، المرحلة، الجنس، القطاع، المدير، التواصل، الأعداد، الموقع، علامة "الأولى للتحسين"، الأولوية) · `SchoolAssignment` (مشرف ↔ مدرسة، من/إلى، نشط) |
| `academic` | التقويم الدراسي | `AcademicYear` · `Term` · `StudyWeek` (رقم، بداية/نهاية) · `Holiday` |
| `assessments` | محرّك الاستمارات | `FormTemplate` (نوع الزيارة + المرحلة) · `FormItem` · `VisitCycle` (مسار مدرسة لنوع زيارة في عام: يُستكمل عبر زيارات متتالية) · `FormInstance` (استمارة الزيارة + حالة سير العمل) · `ItemResponse` (نعم/لا/مؤجَّل، نوع السبب، السبب، مُرحَّل من) · `FormReview` (ملاحظات مدير القسم/مدير الإدارة/مساعد الشؤون التعليمية) |
| `operations` | العمليات الميدانية وبوابة المشرف | `ActivityType` · `NonExecutionReason` (قاطع/غير قاطع) · `WeeklyPlan` · `PlanItem` (زيارة أو نشاط، يوم، مدرسة، نوع الزيارة، النمط حضوري/عن بعد، المرحلة) · `Visit` · `ExecutionLog` (تنفيذ يومي: نُفّذ/لم يُنفّذ + السبب) |
| `command` | مركز القيادة للإدارة | بلا نماذج — مؤشرات محسوبة من البيانات أعلاه |

## القواعد الجوهرية
- **أنواع الزيارات**: دعم · أداء فني (تخطيط ← مراجعة ← تقويم) · الأولى للتحسين (تظهر فقط لمن أُسندت إليه مدرسة موسومة بها). النمط: حضورية/عن بعد.
- **الاستمارة**: كل بند نعم/لا؛ "لا" تتطلب نوع السبب (غير قاطع: عدم التواجد · قاطع: استحالة التوفير) ونص السبب. البند غير المتناول يُعلَّم "مؤجَّل" صراحةً. لا إقفال مع حقل فارغ.
- **الترحيل**: "لا/غير قاطع" و"مؤجَّل" تُرحَّل لزيارة المدرسة التالية في المسار نفسه؛ "نعم" و"لا/قاطع" تُغلق البند. يكتمل المسار حين لا يبقى بند مُرحَّل.
- **الإقفال شرط للتخطيط**: وجود استمارة غير مقفلة لزيارة منفذة يمنع إنشاء خطة الأسبوع التالي.
- **سير المراجعة**: مسودة ← مقفلة (عند مدير القسم) ← مراجعة القسم ← مراجعة مدير الإدارة ← معتمدة نهائياً (مساعد الشؤون التعليمية)، ولكلٍّ ملاحظاته.
- **القياس**: لا ترتيب بعدد الزيارات؛ مؤشر مركّب يراعي العبء والتغطية والتنفيذ والأولويات والمتابعة، و"—" عند نقص البيانات.

## المراحل
1. الهيكل + الحسابات وOTP + البيانات الأساسية والتقويم.
2. محرّك الاستمارات (الترحيل، الإقفال، المراجعة).
3. العمليات: الخطة الأسبوعية، التنفيذ اليومي، بوابة المشرف.
4. مركز القيادة + بيانات تجريبية + اختبارات شاملة.
