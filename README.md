# بوابة الزيارات

مركز تشغيل وقرار للإشراف التربوي، وليست مجرد أداة لتسجيل الزيارات. الدورة: **بيانات ← إسناد ← تخطيط ← تنفيذ ← متابعة ← قياس ← قرار**.
مبنية بـ Django بواجهة عربية من اليمين إلى اليسار (RTL). خطة التطبيقات والنماذج في [`docs/PLAN.md`](docs/PLAN.md).

## التشغيل

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo --activity   # بيانات تأسيسية وتجريبية (اختياري)
python manage.py runserver
```

الدخول برمز تحقق يُرسل إلى البريد. في بيئة التطوير يُطبع الرمز في الطرفية.
الحسابات التجريبية:

| البريد | الدور |
|---|---|
| `s1@example.com` … `s4@example.com` | مشرفون |
| `manager@example.com` | مدير قسم |
| `director@example.com` | مدير الإدارة |
| `assistant@example.com` | مساعد الشؤون التعليمية |
| `admin@example.com` | مسؤول النظام، وله الوصول إلى «إدارة البيانات» |

للإنتاج اضبط: `DJANGO_SECRET_KEY` و`DJANGO_DEBUG=0` و`DJANGO_ALLOWED_HOSTS`، وإعدادات البريد `DJANGO_EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend` و`EMAIL_HOST` و`EMAIL_HOST_USER` و`EMAIL_HOST_PASSWORD` و`DEFAULT_FROM_EMAIL`.

## الاختبارات

```bash
python manage.py test
```

## الواجهات

- **بوابة المشرف** (`/me/`): نشاط اليوم، خطتي، تسجيل التنفيذ، مدارسي المسندة، سجل الخطط، واستمارات الزيارات.
- **مركز القيادة** (`/command/`): مؤشرات الإسناد والتغطية والتخطيط والتنفيذ، ومسار الاستمارات، والأولويات التي لم تُزر، وأسباب عدم التنفيذ، وقراءة متوازنة لأداء المشرفين. يُعرض «—» حين لا تكفي البيانات للحكم.
- **مراجعة الاستمارات** (`/forms/reviews/`): تمر الاستمارة على مدير القسم ثم مدير الإدارة ثم مساعد الشؤون التعليمية.
- **إدارة البيانات** (`/admin/`): القطاعات، والمدارس مع إسنادها، والمستخدمون، والتقويم (مع توليد الأسابيع آلياً)، وقوالب الاستمارات وبنودها، وأنواع الأنشطة، وأسباب عدم التنفيذ.

## القواعد المطبّقة

- **الأولى للتحسين**: هذا النوع من الزيارات يظهر فقط للمشرف المسندة إليه مدرسة موسومة بهذه العلامة.
- **الأداء الفني**: مراحله متتابعة (تخطيط ← مراجعة ← تقويم)، ولا تبدأ مرحلة قبل إقفال استمارة المرحلة السابقة.
- **الإجابة بـ«لا»**: تتطلب تحديد نوع السبب وكتابة نصه.
  - «عدم التواجد» سبب غير قاطع، فيُرحَّل البند إلى الزيارة التالية للمدرسة.
  - «استحالة التوفير» سبب قاطع، فلا يُرحَّل البند.
- **البند غير المكتمل**: يُعلَّم صراحةً «لم يُستكمل» مع توضيح، ثم يُرحَّل.
- **الإقفال**: لا تُقفل الاستمارة وفيها حقل فارغ، بما في ذلك الملخص والتوصيات.
- **الاستمارة المفتوحة** (مسودة أو معادة للمشرف): تمنع إنشاء خطة أسبوع لاحق.
- **ترتيب المشرفين**: يعتمد على مؤشر متوازن (التغطية، والتنفيذ، وانتظام الخطط، والأولويات، والمتابعة، والنتائج)، لا على عدد الزيارات وحده.
